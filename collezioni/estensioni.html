Estensioni

Le mie estensioni di FireFox

Ho già detto da qualche parte che ho millemila estensioni di Firefox. Beh, eccole!

Sono divise in categorie in base a quando le clicco.

  1. #0: Installate e basta, perché funzionano senza problemi. Più che altro sono robe per la privacy.
  2. #1: Qualche volta, ovvero quelle che mi servono per dei compiti specifici e quindi le prendo al bisogno.
  3. #2: Ogni giorno, quelle assolutamente essenziali, che di solito attivo e disattivo venti volte in una giornata, tra cui alcune per leggere meglio e altre per controllare l'accessibilità.
  4. #3: Specifiche, quelle che servono solo per un sito o un gruppo di siti.

Installate e basta

Decentraleyes
Protegge dal tracciamento tramite CDN centralizzato "gratis".

TrackMeNot
Protect against data profiling by search engines

Don't Accept image/webp
Strip image/webp from Accept: headers, which should discourage servers from replacing JPEG and PNG images with WebP images.

Were You Typing
Notifies you when you type something if no text boxes are currently selected, meaning the inputed text isn't going anywhere.

Fandom Enhance
Removes bloat from any fandom.com wiki

Don't track me Google
Removes the annoying link-conversion at Google Search/maps/...

Opt-out for Analytics™
Impedisce alle API JavaScript di Google Analytics e Tag Manager di raccogliere dati e registrare l'utente

Image Alt Text Reader
Reads the alt text of images on the current page

Flagfox
Mostra l'ubicazione del server mediante la bandiera nazionale

No Homo-Graph
Checks for homo-graphs in the domain name of the current website to prevent phishing.

SmartUpscale
Disables blur for images shown at integer zoom levels.

Tab Unloader
Unload tabs to free up system resources

Shinigami Eyes
Highlights transphobic/anti-LGBT and trans-friendly subreddits/users/facebook pages/groups with different colors.

Save webP as PNG or JPEG
Convert webP images to PNG or JPEG (with choice of quality) for downloading. Right-click context menu calls up format options overlaid on the image.

Byelinear
Encourages the HTML-Renderer to use high-contrast - nearest-neighbor-like image and video scaling.

Consent-O-Matic
Automatic handling of GDPR consent forms

PmPractices Disable Extensions
